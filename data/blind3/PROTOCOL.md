# Third independent PDF audit

Pre-registered before selection or parsing. Code and this protocol are committed before running `pick-blind3.py`; the manifest records that commit. No core changes until the run and its reviews are complete.

- Selection: the 12 categories in `pick-blind3.py`, newest primary-category article with a downloadable PDF and at least 10 main-bibliography entries in its source .bbl; two newest eligible PLOS ONE research articles, counted from JATS. Exclude every previously downloaded arXiv paper, including failed candidates. Record rejected candidates and reasons. Source availability is a sampling restriction, not evidence of general PDF performance.
- Do not run the parser to select or replace papers. Extraction failures stay in the denominator and have zero verified references. Report candidate/download success and selected-PDF extraction success separately. Evaluate the main bibliography; separately numbered supplementary bibliographies are outside the current product scope and must be disclosed.
- Freeze: record full git commit, clean source state, query time, fixed PDF version/URL, source count method and runtime. Refuse to overwrite any results. Keep one empty in-memory cache per run; papers sequentially, six reference workers, 40-second per-reference budget, the same settings as the browser. No paid keys or quota. Start after OpenAlex's response headers show a positive free allowance, and record any later exhaustion.
- Completeness: report parsed count and source count per paper; cap the numerator per paper. Also report excess entries, zero-entry PDFs, and the number of references outside the main bibliography where identifiable. Count agreement alone does not prove correct segmentation.
- Preserve every parsed reference, all parsed fields, verdict, matched record and issue. Review every flag against the PDF and publisher/identifier record: real error / false alarm / uncertain, with a source URL and explanation. Minor cosmetic differences are false alarms. No observed flags is not perfect precision: report precision as undefined.
- Seeded samples: three randomly selected verified references per paper for missed errors; five references per paper sampled independently of verdict for segmentation and title/author/year/venue/identifier correctness against the PDF. Missing applicable fields are errors; fields absent from the PDF are N/A. Record PDF page/label, expected fields, pass/fail/N/A and notes. Do not infer field correctness from count completeness or health heuristics.
- Report reference flag precision (real / all flags, uncertain kept in denominator), false alarms / all extracted references, verified coverage, unverifiable share, unchecked share, parse and live-verification time (per paper, median and range), and all host failures. Also report the conditional false-positive rate only if its genuine-reference denominator was independently established; otherwise label it unavailable.
- Targets: false alarms / all references ≤2%, main-bibliography count completeness ≥95%, while preserving useful verification coverage. Compare coverage and abstention with both historical blind runs; do not obtain a pass by dropping hard papers or relabelling flags as abstentions. A low-error result with substantially reduced coverage is not a pass.
- This round ends the independent-test sequence. Only bounded fixes for substantial product failures afterward; report this frozen result unchanged. Do not select models or thresholds using this set, HALLMARK test or Citation-Integrity test.
